The description in step 1 says the CLI copies files into `app/(auth)/mfa-enroll`, but that is an App Router path. The `add next` command accepts an `--area` flag (e.g. `--area /admin`), and on a Pages Router project the destination would be different. More importantly, the current text implies the route is always placed at that fixed path regardless of the flag value, which is misleading. The improvement clarifies that the destination directory is derived from `--area` and distinguishes App Router vs Pages Router output paths.
