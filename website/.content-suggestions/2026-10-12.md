The install step says the CLI copies files into `app/(auth)/mfa-enroll`, but the command uses `--area /admin`. Those two things don't match, and a developer following the docs will be confused when the actual output path is under `/admin` instead. The description should reflect what the `--area` flag actually controls.

Additionally, the Pages Router file path claim is wrong for a Pages Router project — `app/(auth)/mfa-enroll` is an App Router path. Since the page itself says the kit "Works on Next.js App Router and Pages Router", the install description should note that the output path varies by router, not hardcode the App Router path.
